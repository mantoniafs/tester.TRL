⚙ Integração com Airtable

Para salvar os resultados automaticamente numa base Airtable, siga os passos abaixo e cole a URL do webhook.

Passo 1 — No Airtable, crie uma base com as colunas:
Nome da Solução · Responsável · Data · Tipo de Solução · TRL · Critérios Respondidos · Critérios Atendidos · % Conformidade · Detalhes por Nível
Passo 2 — Em Automations no Airtable, crie uma automação com gatilho "When webhook received". Copie a URL gerada.
Passo 3 — Configure a ação da automação para criar um registro na base com os campos acima mapeados para o JSON recebido.
Alternativa mais simples — Use Make.com (gratuito) ou n8n: crie um fluxo que recebe webhook → cria registro no Airtable. Mais fácil de mapear os campos.
